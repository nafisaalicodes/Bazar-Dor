#বাজার দর | BazarDor

BazarDor is a web application designed to help users explore and compare the daily prices of essential products across different markets in Bangladesh. It provides useful price insights, category-based browsing, and market-wise comparisons through a clean, responsive, and user-friendly interface.

##Key Features
**Daily Price Tracking**
View today's prices of essential products and monitor price changes.
**Price Trend Highlights**
Discover products with the highest price increases and decreases.
**Product Categories & Sorting**
Browse products by category and sort them by price from low to high or high to low.
**Market Price Comparison**
Explore minimum, maximum, average, and market-wise product prices.
**Secure Authentication**
Sign up and sign in using email and password, Google, or GitHub with Better Auth.

##Technologies Used
**Next.js** — React framework with App Router 
**React** — User interface development 
**TypeScript** — Type-safe development 
**Tailwind CSS** — Responsive styling 
**Better Auth** — Authentication and session management 
**MongoDB** — Database integration 
**Vercel** — Deployment and hosting
