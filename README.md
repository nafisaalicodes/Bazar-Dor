# বাজার দর | BazarDor

BazarDor is a daily market price tracking web application designed to help users explore and compare the prices of essential products across different markets in Bangladesh. The application provides price trend insights, category-based product browsing, market-wise price comparisons, and a responsive user interface for a smooth experience across different devices.

## Technologies Used

* **Next.js** — React framework with App Router
* **React** — Building interactive user interfaces
* **TypeScript** — Type-safe application development
* **Tailwind CSS** — Responsive and modern UI styling
* **Better Auth** — Authentication and session management
* **MongoDB** — Database integration
* **Vercel** — Application deployment and hosting

## Key Features

1. **Daily Price Tracking**

   * View today's prices of essential products in Bangladesh.
   * Monitor price changes to understand daily market trends.

2. **Price Trend Highlights**

   * Explore products with the highest price increases and decreases.
   * Identify changing prices through visual indicators.

3. **Product Categories & Sorting**

   * Browse products by category.
   * Sort products by price from low to high or high to low.

4. **Market Price Comparison**

   * View minimum, maximum, and average product prices.
   * Compare prices across different markets.

5. **User Authentication**

   * Sign up and sign in using email and password.
   * Authenticate using Google or GitHub with Better Auth.
   * Access protected product details after signing in.
