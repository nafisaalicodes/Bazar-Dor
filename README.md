Daily Market Price Tracker for Bangladesh 🇧🇩

BazarDor is a web application that helps users explore daily market prices of essential products in Bangladesh. Users can compare prices across different markets, track price changes, browse products by category, and access detailed market price information through a clean and responsive interface.

 Key Features
 Daily Price Tracking: View today's prices and price changes for essential products.
 Price Trend Highlights: Explore products with the highest price increases and decreases.
 Product Categories & Sorting: Browse products by category and sort them by price from low to high or high to low.
 Market Price Comparison: View minimum, maximum, average, and market-wise prices on product details pages.
 Authentication: Sign up and sign in using email and password, Google, or GitHub with Better Auth.

Technologies Used
Next.js — React framework with App Router
React — User interface development
TypeScript — Type-safe development
Tailwind CSS — Responsive styling
Better Auth — Authentication and session management
MongoDB — Database integration
Vercel — Deployment and hosting
